## Overview

BoundBot is an AI-driven customer support solution designed for SaaS businesses. Before we dive into the setup steps, here is a look at the final workspace dashboard where you can manage agents, track leads, and monitor conversation performance.

![Dashboard Overview](/images/dashboard-overview.png)

---

## Core Capabilities

- **AI Agent (b Assistant)**: A friendly, automated assistant trained to handle initial customer inquiries.
- **Knowledge Base**: Custom FAQs and data sources used to train your agent for accurate responses.
- **Live Playground**: A secure environment to test agent behavior before deploying to production.
