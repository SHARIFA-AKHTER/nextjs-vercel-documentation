## Visual Customization 🎨

BoundBot provides a flexible **Customize Chat UI** panel that allows you to modify the widget's appearance without writing any code.

![Chat Widget Customization](/images/widget-customize.png)

### Theme & Layout Settings
You can adjust how the chat box sits on your website:
* **Theme**: We have selected the **Dark** theme for a modern, sleek look.
* **Position**: The widget is set to the **Bottom Right** of the screen for optimal user accessibility.
* **Height**: The chat window height is configured at **780px**.
* **Border Radius**: A custom border radius has been applied to soften the edges of the chat box.

### Colors & Branding
Maintain brand consistency by customizing the color palette:
* **Primary Color**: Set to a custom black (`#000000`) to provide a high-contrast, premium feel.
* **Bubble Text Color**: Configured in white (`#ffffff`) for maximum readability.

## Starter Suggestions 💡

To help users initiate a conversation, you can add **Quick-reply chips** that appear before the first message. 

We have configured the following suggestions:
1. **"What are your business hours?"**
2. **"Help me pick the right product."**
3. **"Can you explain your refund policy?"**

## Technical Performance ⚙️

As you customize these settings, the dashboard performs real-time API calls (e.g., `/integrations`, `/bots`) to ensure your changes are saved and synced instantly. 

> **Developer Note:** Once you are happy with the customization, navigate to the **Channels** section to get your production `iframe` or `script` embed code.
